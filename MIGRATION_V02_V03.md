# Migration v0.2 → v0.3

La v0.3 est additive : les exercices v0.2 restent présents mais reçoivent des métadonnées Content API 3.0 (`activity_type`, `renderer_id`, `skill_dimensions`, `scoring`, `review`).

Les cours v0.2 sont enrichis directement avec `subtitle`, `prerequisites`, `content_blocks`, `mastery_contract` et les règles de session.

Nouveautés majeures :

- cours réellement explicatifs ;
- catalogue stable de renderers ;
- activités de phrase à compléter ;
- dictée/écoute ;
- prononciation mot + phrase ;
- politiques de maîtrise et SRS versionnées dans GitHub ;
- chapitre soft-unlock puis maîtrise différée ;
- packs + hashes pour synchronisation incrémentale ;
- provenance explicite entre sources utilisateur et expansion pédagogique.
